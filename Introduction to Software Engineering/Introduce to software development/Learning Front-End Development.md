# Front-End Web Development

## Summary

Front-end development creates the part of a website that users see and interact with. HTML provides the structure, CSS controls the appearance, and JavaScript adds behavior and interactivity. Front-end developers also use CSS extensions and JavaScript frameworks or libraries to build maintainable, responsive websites.

## Core concepts

### Main front-end technologies

| Technology | Purpose | Example |
|---|---|---|
| **HTML** | Defines the page’s structure and content | Text, images, links, buttons, and page sections |
| **CSS** | Controls visual presentation | Colors, fonts, spacing, and layouts |
| **JavaScript** | Adds interactivity and behavior | Making a login button perform an action |

These technologies work together: HTML creates a button, CSS styles it, and JavaScript makes it functional.

### CSS extensions

- **Sass — Syntactically Awesome Style Sheets:** Extends CSS with features such as variables, nested rules, and imports.
- **Less — Leaner Style Sheets:** Adds functions and organizational features to CSS while remaining backward-compatible.
- **Less.js:** Converts Less styles into standard CSS.

Both Sass and Less help developers create and organize stylesheets more efficiently.

### Adaptive and responsive design

| Design approach | Behavior |
|---|---|
| **Adaptive design** | Displays a predefined version designed for a particular screen size |
| **Responsive design** | Automatically resizes and rearranges the same page to fit the device |

For example, an adaptive site might show less information on a phone, while a responsive site rearranges its content so the same features remain accessible.

### JavaScript frameworks and libraries

| Technology | Main characteristics |
|---|---|
| **Angular** | A comprehensive framework with built-in capabilities such as routing and form validation |
| **React.js** | A library for building and rendering reusable page components; features such as routing require additional tools |
| **Vue.js** | Focuses on the user-interface layer and visual components; flexible and easy to integrate with other technologies |

## Front-end developer responsibilities

A front-end developer:

- Builds and styles the visible structure of websites.
- Creates intuitive and interactive user experiences.
- Supports different browsers, operating systems, and devices.
- Implements adaptive or responsive layouts.
- Maintains and upgrades websites as technologies evolve.

## Takeaway

HTML supplies the structure, CSS supplies the presentation, and JavaScript supplies the behavior. Effective front-end development combines all three with responsive design and suitable frameworks or libraries to produce attractive, interactive, and broadly compatible websites.
