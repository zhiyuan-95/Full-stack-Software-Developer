# Overview of Web and Cloud Development

## Summary

Websites and cloud applications use a client–server model. A browser requests content from a server, which responds with the files and data needed to display the application. Web development is commonly divided into front-end, back-end, and full-stack work.

## Core concepts

### Client–server communication

1. The user enters a URL into a browser.
2. The browser, acting as the client, sends a request to the server.
3. The server returns the requested files and data.
4. The browser renders the website for the user.

Popular browsers include Google Chrome, Microsoft Edge, Mozilla Firefox, and Apple Safari.

### Main web technologies

| Technology | Purpose |
|---|---|
| HTML | Defines the page’s structure and content |
| CSS | Controls presentation, styling, and layout |
| JavaScript | Adds interactivity and dynamic behavior |

### Static and dynamic content

- **Static content** is stored on the server and returned largely as previously created.
- **Dynamic content** is generated when requested and may use databases or other applications.
- Most websites combine both types to provide a useful, responsive experience.

### Cloud applications

Cloud applications also request content and services from servers. They are designed to work with cloud-based infrastructure, storage, processing, and related services, which can make them highly scalable and resilient.

### Development areas

| Area | Main responsibility | Common technologies or concerns |
|---|---|---|
| Front end | Everything users see and interact with on the client side | HTML, CSS, JavaScript, frameworks, and libraries |
| Back end | Server-side logic and functionality | Authentication, security, relational databases, and NoSQL databases |
| Full stack | Both client-side and server-side development | Combined front-end and back-end knowledge |

On larger projects, back-end developers may collaborate with database administrators.

## Development tools

A **code editor** provides the environment for writing and editing source code.

An **Integrated Development Environment (IDE)** adds capabilities such as:

- Building and compiling code
- Debugging
- Supporting multiple programming languages
- Integrating with Git and GitHub
- Installing extensions and themes

Examples mentioned include Sublime Text, Atom, Vim, VS Code, Visual Studio, Eclipse, and NetBeans.

## Takeaway

A web developer should understand how browsers and servers communicate, how HTML, CSS, and JavaScript work together, and how front-end and back-end responsibilities differ. Full-stack development combines both areas, while code editors and IDEs help developers create, test, debug, and manage their code.
