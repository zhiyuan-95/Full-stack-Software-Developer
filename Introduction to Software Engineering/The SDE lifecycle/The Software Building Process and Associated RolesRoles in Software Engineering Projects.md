# Roles in Software Engineering Projects

## Summary

Software projects involve several specialized roles. Titles vary by company and methodology, and not every project includes every role. Each role contributes to planning, design, development, quality, operations, or communication.

## Key roles and responsibilities

| Role | Main responsibilities |
|---|---|
| **Project Manager** | Plans schedules and budgets, allocates resources, executes the project plan, and facilitates team communication. |
| **Scrum Master** | Agile counterpart to a project manager; removes obstacles and promotes team success, collaboration, and communication. |
| **Stakeholders** | Define requirements, clarify needs, provide feedback, and may participate in beta and acceptance testing. Includes customers, users, decision-makers, and administrators. |
| **System/Software Architect** | Designs and communicates the software’s architecture and technical structure. Provides technical guidance throughout the SDLC. |
| **UX Designer** | Defines how users experience and interact with the software, balancing ease of use with functional requirements. |
| **Software Developer** | Writes the code, implements the architecture, satisfies software requirements, and incorporates UX designs. |
| **Tester/QA Engineer** | Creates and executes test cases, identifies defects, verifies customer requirements, and reports problems to developers. |
| **Site Reliability/Ops Engineer** | Connects development with operations, manages incidents, automates processes, troubleshoots systems, and protects reliability. |
| **Product Manager/Owner** | Establishes the product vision, understands stakeholder and user needs, guides development, and ensures the product delivers value. |
| **Technical Writer/Information Developer** | Explains technical subjects to nontechnical audiences through user manuals, reports, white papers, press releases, and other documentation. |

## Core concepts

- Job titles can differ between organizations and development approaches.
- Traditional SDLC projects commonly use a **project manager**, while Agile teams use a **Scrum master**.
- A project manager emphasizes planning and project execution; a Scrum master emphasizes people, communication, and team effectiveness.
- Successful software development requires collaboration among business, design, engineering, testing, operations, and documentation roles.
- Stakeholder feedback helps ensure the finished software addresses real customer and user needs.

## Takeaway

Each role has distinct responsibilities, but all roles contribute to the shared goal of delivering reliable, useful software that satisfies stakeholder requirements.
