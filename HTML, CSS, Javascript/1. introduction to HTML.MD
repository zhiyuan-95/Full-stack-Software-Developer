# HTML and HTML5 Fundamentals

## What Is HTML?

**HTML** stands for **Hypertext Markup Language**. It is the markup language used to structure documents displayed as web pages.

Originally designed for sharing scientific documents, HTML evolved to support many types of web content.

## Elements, Tags, and Rendering

**HTML elements** are the building blocks of a web page. They identify the purpose of content, such as:

- Paragraphs
- Lists
- Tables

Elements are represented by **tags**. Browsers interpret these tags to determine how the content should be structured and rendered; the tags themselves are not normally displayed.

## Evolution of HTML

HTML has evolved continuously since its introduction in the early 1990s through work involving:

- **CERN** — European Organization for Nuclear Research
- **IETF** — Internet Engineering Task Force
- **W3C** — World Wide Web Consortium
- **WHATWG** — Web Hypertext Application Technology Working Group

The W3C issued recommendations as HTML gained new features and its specifications changed. WHATWG initially developed recommendations independently.

In **2007**, the W3C created a working group to collaborate with WHATWG on HTML5:

- W3C published its specification under W3C copyright.
- WHATWG maintained a version with a less restrictive license.
- Both organizations contributed to HTML5’s development.

## HTML5 Objectives and Capabilities

The HTML5 specification aimed to:

1. Define a single language that can use either **HTML syntax** or **XML syntax**.
2. Provide a processing model that interoperates with earlier HTML implementations.
3. Improve document markup.
4. Add markup and APIs for common web capabilities, including:
   - Web storage
   - Video
   - Audio

## HTML vs. HTML5

In ordinary web development, **HTML** and **HTML5** are often used interchangeably. The term **HTML5** is mainly useful when distinguishing it from earlier HTML versions or discussing features introduced with HTML5.

In this course, **HTML means HTML5 unless stated otherwise**.

## Key Takeaway

HTML structures web-page content by labeling elements with tags. HTML5 expanded the language while preserving compatibility with earlier HTML and adding native support for modern capabilities such as storage, video, and audio.
