Cascading Style Sheets (CSS)

CSS is a style sheet language that controls how HTML elements are displayed. HTML supplies a page's content and structure, while CSS adds its visual design. Combined with HTML5 and JavaScript, CSS helps developers build rich, interactive pages for desktop and mobile devices without relying on browser plug-ins such as the Flash media player.

## Learning objectives

After completing this lesson, you should be able to:

- Explain what CSS is.
- Use CSS to format HTML elements.
- Connect CSS to HTML documents to format web pages.

## Separating content from presentation

Websites benefit from keeping data and structure separate from design:

- **HTML** sends the content and structure to the browser.
- **CSS** determines how that content is presented.

This separation makes a site's design easier to maintain and reuse. It also allows content to be rendered differently for accessibility needs and lets machines such as search engines index the content without the visual design interfering.

HTML documents are not limited to visual browser windows. For example, assistive technology can render their content through a speech synthesizer for people with visual impairments. Semantic HTML and separate CSS therefore provide accessibility advantages over content tied to browser plug-ins.

## Why CSS is "cascading"

CSS can apply a uniform appearance across the elements and pages of a website. Styles defined for a parent element are often inherited by its child and descendant elements, although exceptions exist because not every CSS property is inherited.

When multiple rules apply to the same element, CSS resolves the conflict according to its cascade and priority rules. For the three placement methods introduced in this lesson, the stated order of precedence is:

1. **Inline CSS** — highest priority
2. **Internal CSS**
3. **External CSS** — lowest priority of the three

> This is the lesson's simplified precedence model. The complete CSS cascade also considers factors such as selector specificity and source order.

## What CSS can control

CSS style rules can define the appearance of:

- Fonts and text
- Colors and backgrounds
- Sizes
- Borders and spacing
- Positioning and visual effects
- Tables and lists

## CSS rule structure and selectors

A CSS rule associates a **selector** with one or more style declarations:

```css
selector {
    property: value;
}
```

The lesson introduces three selector forms:

| Selector type | CSS form | Purpose |
|---|---|---|
| HTML element | Element name, such as `a`, `div`, `li`, or `label` | Selects elements with that HTML tag |
| ID | A name preceded by `#` | Selects an element by its `id` |
| Class | A name preceded by `.` | Selects elements assigned to that class |

## Establishing a base style

A site design should begin with a base style, commonly applied to the `<body>` element. The lesson's example establishes the following defaults:

- An off-white background with `background-color`
- Black text with `color`
- No gap between the content and browser-window edges through `margin` and `padding`
- Left-aligned text with `text-align`
- The browser's default font size with `font-size`
- A sans-serif font with `font-family`

Styling `<body>` creates a consistent starting point because many of its text-related settings can be inherited by descendant elements.

## Common CSS values

### Colors

The lesson recommends specifying colors with hexadecimal Red-Green-Blue (RGB) values.

### Sizes

Sizes can be expressed with:

- **Pixels (`px`)** — a fixed CSS measurement.
- **Ems (`em`)** — a value relative to font size; the relevant font size is multiplied by the specified number.
- **Percentages (`%`)** — a value relative to another measurement, such as the size of a containing element.

### Alignment and fonts

- Text can be aligned `left`, `right`, or `center`.
- Floats can be positioned `left` or `right`.
- Vertical alignment values include `top`, `middle`, and `bottom`.
- A font can be a specific typeface, a generic family such as `serif`, `sans-serif`, or `monospace`, or a downloadable font.

## Fluid and fixed layouts

Choosing between a fluid and fixed layout is an important design decision. The best choice depends on the type and amount of content and the website's target audience.

| Layout | Behavior | Common units |
|---|---|---|
| **Fluid** | Element heights and widths can expand or contract in response to the browser window, operating system, and user preferences. | Percentages and `em` units |
| **Fixed** | Element heights and widths use specified values intended to remain constant across browsers and operating systems. | Pixels (`px`) |

Each approach has advantages and disadvantages, so layout should be selected according to the site's content and users rather than by a universal rule.

## Three ways to apply CSS

HTML must tell the browser where to find its CSS. The lesson describes three methods.

### 1. Inline CSS

Inline CSS uses the `style` attribute inside an individual HTML element.

```html
<p style="color: black;">Text</p>
```

It is useful for a single element, but repeated inline styles quickly make an HTML document difficult to read and maintain.

### 2. Internal CSS

Internal CSS places rules inside a `<style>` element in the HTML document, normally for one page.

```html
<head>
    <style>
        p {
            color: black;
        }
    </style>
</head>
```

This method mixes CSS into the HTML file. Copying the same rules into multiple pages also increases each page's size and can increase load time.

### 3. External CSS

External CSS stores rules in a separate style sheet and connects it to an HTML document with a `<link>` element inside `<head>`.

```html
<head>
    <link rel="stylesheet" href="styles.css">
</head>
```

This is the preferred method for styling an entire website because multiple pages can reuse one style sheet, keeping the HTML cleaner and page files smaller.

Although a page can combine inline, internal, and external CSS, the lesson does not recommend relying on all three together because overlapping rules can make the resulting styles harder to manage.

## Key takeaway

CSS separates a website's presentation from its HTML content and structure. Begin with a consistent base style, choose a fluid or fixed layout based on the content and audience, and generally keep shared styles in an external style sheet. HTML can reference CSS inline, internally, or externally; when rules overlap, the CSS cascade determines which style is applied.
