# JavaScript, Sandboxing, and DOM Access

## What Is Scripting?

**Scripting** uses code—most commonly JavaScript—to add behavior and interactivity to web pages. JavaScript can be placed:

Directly inside HTML:

```html
<script>
  console.log("Page loaded");
</script>
```

Or in a separate file:

```html
<script src="app.js"></script>
```

Common uses include:

- Validating forms
- Dynamically changing page content
- Manipulating images
- Responding to user actions

## Browser Scripting

A browser can run a page’s scripts when:

1. The browser supports scripting.
2. The user has scripting enabled.
3. The page’s security context, including any sandbox restrictions, permits execution.

Because scripts can be disabled, blocked, or fail to load, websites should not rely on JavaScript for essential content or basic access. This principle is often called **progressive enhancement**.

## Sandboxed Embedded Content

Embedded third-party content can be restricted using the `sandbox` attribute on an `<iframe>`:

```html
<iframe
  src="https://example.com/content"
  sandbox>
</iframe>
```

A sandboxed frame begins with significant restrictions, including restrictions on scripts, forms, navigation, and other capabilities. Selected permissions can be restored with sandbox tokens:

```html
<iframe
  src="https://example.com/content"
  sandbox="allow-scripts allow-forms">
</iframe>
```

Only grant permissions that the embedded content genuinely requires. Sandboxing is especially useful for untrusted content and **mash-ups**, which combine content from multiple sites.

> The transcript broadly suggests that unsandboxed embedded content receives all the parent page’s permissions. In practice, browser protections such as the **same-origin policy** also limit cross-origin content. The `<iframe sandbox>` attribute adds another layer of restrictions.

## The `Document` Object

When a browser loads an HTML document, it creates a **`Document` object** representing the page. JavaScript accesses it through the global `document` property.

```javascript
console.log(document);
```

The `Document` object provides access to the elements and structure of the page’s DOM tree.

## DOM Tree Accessors

### Document properties

| Accessor | Result |
|---|---|
| `document.head` | The document’s `<head>` element, or `null` if unavailable |
| `document.body` | The document’s `<body>` element, or `null` if unavailable |
| `document.images` | An `HTMLCollection` of the document’s `<img>` elements |
| `document.scripts` | An `HTMLCollection` of the document’s `<script>` elements |

`document.images` and `document.scripts` are **properties**, not functions, so they do not use parentheses.

### Selection methods

#### `getElementById()`

Returns the element whose `id` exactly matches the supplied value:

```javascript
const field = document.getElementById("textField1");
```

IDs should be unique within a document. If no matching element exists, the method returns `null`.

#### `getElementsByTagName()`

Returns a live `HTMLCollection` containing elements with the specified tag name:

```javascript
const paragraphs = document.getElementsByTagName("p");
```

Despite the transcript describing the result as a `NodeList`, this particular method returns an `HTMLCollection`.

## Form-Validation Example

```html
<input id="textField1" type="text">
<button type="button" onclick="textChecker()">Submit</button>

<script>
  function textChecker() {
    const field = document.getElementById("textField1");
    const text = field.value;

    if (text.trim() === "") {
      alert("No text was entered.");
    } else {
      alert(`You entered: ${text}`);
    }
  }
</script>
```

When the user selects **Submit**:

1. `textChecker()` runs.
2. `getElementById("textField1")` retrieves the input element.
3. Its `.value` property provides the entered text.
4. The script tests the value and displays the result in an alert.

## Key Takeaway

JavaScript adds interactivity to HTML but should not be the only way users access essential content. Each loaded page becomes a `Document` object, and DOM accessors such as `document.head`, `document.images`, `getElementById()`, and `getElementsByTagName()` allow scripts to inspect and modify it. Sandboxed iframes help restrict untrusted embedded content.
