# Common HTML Elements

This reading introduces the HTML elements most commonly used to structure basic web pages.

## Learning objectives

After completing this reading, you should be able to:

- Use titles and headings to label information.
- Insert text with the paragraph element.
- Insert line breaks.
- Add links to other pages and sections of the same page.
- Create ordered and unordered lists.
- Create a table of data.
- Insert an image.

## Basic HTML document structure

Every HTML document begins with a `<!DOCTYPE html>` declaration. The `<html>` element contains the entire document, which is divided into two main sections:

- `<head>` contains metadata and other information about the page.
- `<body>` contains the content displayed to the user.

```html
<!DOCTYPE html>
<html>
    <head>
        <!-- Metadata goes here -->
    </head>
    <body>
        <!-- Content goes here -->
    </body>
</html>
```

## Browser tab title

The `<title>` element defines the text displayed on the browser tab. It belongs inside the `<head>` section.

```html
<head>
    <title>Sample Page Title</title>
</head>
```

## Page headings

HTML provides six heading levels: `<h1>` through `<h6>`. They communicate the hierarchy and importance of page sections. By default, `<h1>` appears largest and represents the highest level, while `<h6>` appears smallest and represents the lowest level.

Headings are visible page content, so they belong inside `<body>`.

```html
<body>
    <h1>Most Important (and Largest) Heading</h1>
    <h6>Least Important (and Smallest) Heading</h6>
</body>
```

## Paragraphs

The `<p>` element defines a paragraph of text. It can contain anything from a short sentence to a long passage.

```html
<body>
    <h1>Most Important (and Largest) Heading</h1>
    <p>
        This is some text. The content within this paragraph element can be
        as short or as long as needed.
    </p>

    <h6>Least Important (and Smallest) Heading</h6>
    <p>This is another paragraph of text.</p>
</body>
```

## Line breaks

The `<br>` element forces the following content to begin on a new line. It is useful for content such as addresses or poetry. Because `<br>` is a void element, it does not have a closing tag.

```html
<body>
    <p>
        This is some text that needs to be split up<br>
        here,<br>
        here, and<br>
        here.
    </p>
</body>
```

## Hyperlinks

The `<a>` element creates a hyperlink. Its `href` attribute specifies the destination.

### Link to another website

```html
<a href="https://www.ibm.com">IBM</a>
```

Selecting **IBM** opens the destination in the current browser tab.

To open the destination in a new tab, add `target="_blank"`:

```html
<a href="https://www.ibm.com" target="_blank">IBM</a>
```

### Link within the same page

An empty fragment returns to the top of the current page:

```html
<a href="#">Top of Page</a>
```

A fragment identifier can target an element whose `id` has the same value:

```html
<a href="#top">Top of Page</a>

<!-- Other page content -->

<h1 id="top">Page Title</h1>
```

The same approach links to any other section:

```html
<a href="#section">Link to section</a>

<!-- Other page content -->

<h1 id="section">Section</h1>
```

## Lists

Use `<ul>` for an unordered, bulleted list and `<ol>` for an ordered, numbered list. In both types, each item is enclosed in an `<li>` element.

### Unordered list

```html
<ul>
    <li>This is a bullet point.</li>
    <li>The items have no particular order.</li>
    <li>Each item appears as a bullet rather than a number.</li>
</ul>
```

### Ordered list

```html
<ol>
    <li>This is an ordered list.</li>
    <li>The items have a particular order.</li>
    <li>Each item is numbered, starting from 1.</li>
    <li>This is the fourth item in the list.</li>
</ol>
```

## Tables

The following elements create an HTML table:

- `<table>` contains the complete table.
- `<tr>` defines a table row.
- `<th>` defines a heading cell for a row or column.
- `<td>` defines a standard data cell.

The example produces three columns and three rows of data beneath a heading row:

| Heading 1 | Heading 2 | Heading 3 |
| --- | --- | --- |
| H1 - Data Item 1 | H2 - Data Item 1 | H3 - Data Item 1 |
| H1 - Data Item 2 | H2 - Data Item 2 | H3 - Data Item 2 |
| H1 - Data Item 3 | H2 - Data Item 3 | H3 - Data Item 3 |

```html
<table>
    <tr>
        <th>Heading 1</th>
        <th>Heading 2</th>
        <th>Heading 3</th>
    </tr>
    <tr>
        <td>H1 - Data Item 1</td>
        <td>H2 - Data Item 1</td>
        <td>H3 - Data Item 1</td>
    </tr>
    <tr>
        <td>H1 - Data Item 2</td>
        <td>H2 - Data Item 2</td>
        <td>H3 - Data Item 2</td>
    </tr>
    <tr>
        <td>H1 - Data Item 3</td>
        <td>H2 - Data Item 3</td>
        <td>H3 - Data Item 3</td>
    </tr>
</table>
```

## Images

The `<img>` element embeds an external or local image in a page.

Important attributes include:

- `src` specifies the image URL or file path.
- `alt` supplies alternative text if the image cannot load and helps screen-reader users understand the image.
- `width` and `height` optionally set its displayed dimensions in pixels.

For a local image, use a path relative to the HTML document's location.

```html
<!-- External image -->
<img
    src="https://upload.wikimedia.org/wikipedia/commons/thumb/5/51/IBM_logo.svg/440px-IBM_logo.svg.png"
    alt="IBM Logo"
    width="300"
    height="300"
>

<!-- Local image -->
<img
    src="images/IBMlogo.png"
    alt="IBM Logo"
    width="300"
    height="300"
>
```

Like `<br>`, `<img>` is a void element and does not require a closing tag.

## Element reference

| Element | Purpose | Section |
| --- | --- | --- |
| `<!DOCTYPE html>` | Declares an HTML5 document | Before `<html>` |
| `<html>` | Contains the complete HTML document | Document root |
| `<head>` | Contains metadata | Document metadata |
| `<title>` | Sets the browser tab title | `<head>` |
| `<body>` | Contains visible page content | Document body |
| `<h1>`–`<h6>` | Define heading levels | `<body>` |
| `<p>` | Defines a paragraph | `<body>` |
| `<br>` | Inserts a line break | `<body>` |
| `<a>` | Creates a hyperlink | `<body>` |
| `<ul>` / `<ol>` | Create unordered or ordered lists | `<body>` |
| `<li>` | Defines a list item | Inside `<ul>` or `<ol>` |
| `<table>` | Creates a table | `<body>` |
| `<tr>` | Defines a table row | Inside `<table>` |
| `<th>` | Defines a heading cell | Inside `<tr>` |
| `<td>` | Defines a data cell | Inside `<tr>` |
| `<img>` | Embeds an image | `<body>` |

## Takeaway

A basic HTML page combines metadata in `<head>` with visible content in `<body>`. Headings and paragraphs organize text; links connect resources and page sections; lists group related items; tables structure data into rows and columns; and images add visual content.
