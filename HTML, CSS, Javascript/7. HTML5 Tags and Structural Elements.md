# HTML5 Elements and Semantic Structure

## 1. Introduction to HTML5 Elements

HTML5 introduced new elements that provide semantic meaning, structural organization, and multimedia capabilities for web pages.

### Key concepts

- HTML elements define the structure and content of a webpage.
- HTML5 provides dedicated elements for different types of content.
- Many HTML5 elements have intuitive names that describe their purpose.
- Semantic elements make HTML documents easier to understand, maintain, and navigate.
- CSS controls how these elements are visually presented.

### Examples of HTML5-specific elements

| Element        | Description                                                                    |
| -------------- | ------------------------------------------------------------------------------ |
| `<article>`    | Defines independent, self-contained content.                                   |
| `<section>`    | Defines a thematic section within a document.                                  |
| `<header>`     | Contains introductory content or headings for a page or section.               |
| `<footer>`     | Contains footer information for a page or section.                             |
| `<nav>`        | Groups major navigational links.                                               |
| `<aside>`      | Contains additional or indirectly related content.                             |
| `<figure>`     | Groups self-contained content such as images, graphics, or code examples.      |
| `<figcaption>` | Provides a caption for a `<figure>`.                                           |
| `<audio>`      | Embeds audio content into a webpage.                                           |
| `<video>`      | Embeds video content into a webpage.                                           |
| `<canvas>`     | Provides a drawing surface for graphics, typically controlled with JavaScript. |

## 2. Division-Based Layouts: The `<div>` Element

### 2.1 What is a `<div>`?

The `<div>` (division) element is a generic container used to group different parts of an HTML document.

It existed before HTML5 and remains widely used in modern web development.

A division-based layout separates a webpage into logical areas, making it easier to apply styles and organize content.

For example, a webpage might be divided into:

- A page title or header area
- A navigation bar
- An image display area
- Text content sections
- Thumbnail image areas
- A footer

### 2.2 Characteristics of `<div>`

- It is a generic block-level container.
- It does not have intrinsic semantic meaning.
- It groups related HTML elements.
- CSS can apply different styles to each division.
- HTML5 semantic elements can be placed inside `<div>` containers.

Example:

```

<div class="container">
    <div class="title">
        <h1>Welcome to My Website</h1>
    </div>

    <div class="content">
        <p>This is the main content.</p>
    </div>
</div>

```

Explanation: Both containers organize content, but neither describes the meaning or purpose of that content.

## 3. Semantic vs. Non-Semantic Elements

### 3.1 Semantic elements

A semantic element communicates the meaning or function of its content, rather than simply acting as a container.

Examples:

- `<p>` indicates a paragraph.
- `<article>` identifies independent content.
- `<nav>` identifies navigation links.
- `<section>` identifies a thematic section.

### 3.2 Non-semantic elements

Non-semantic elements do not describe the meaning of their contents.

Examples:

- `<div>` is a generic block-level container.
- `<span>` is a generic inline container.

### Comparison

| Feature       | Semantic elements                                 | Non-semantic elements                       |
| ------------- | ------------------------------------------------- | ------------------------------------------- |
| Purpose       | Describe the role of content                      | Group or organize content                   |
| Examples      | `<article>`, `<nav>`, `<section>`                 | `<div>`, `<span>`                           |
| Meaning       | Explicit semantic meaning                         | No specific semantic meaning                |
| Readability   | Makes document structure clearer                  | Meaning depends on context                  |
| Accessibility | Can help assistive technologies interpret content | Does not inherently identify a content role |

Key takeaway: Prefer semantic HTML5 elements when they accurately describe the content. Use `<div>` or `<span>` when a generic container is sufficient.

## 4. HTML5 Structural Elements

HTML5 introduces dedicated elements to organize content according to its purpose.

Example: Semantic structure of a webpage

`<header>`

Website title, logo, introductory content

`<nav>`

Home | Articles | About | Contact

`<main>`

`<article>`

`<header>`

Article title

`<section>`

Introduction

`<figure>`

`<figcaption>`

`<section>`

Main discussion

`<aside>`

Related articles

Additional links

Supporting information

`<footer>`

Copyright, contact information, related links

Conceptual example. HTML elements define meaning and structure; CSS determines their visual placement.

### 4.1 `<article>` — Independent Content

Defines a self-contained piece of content that can stand independently from the rest of the webpage.

Common examples include news articles, blog posts, and forum posts.

```

<article>
    <h2>Latest Technology News</h2>
    <p>AI is transforming many industries.</p>
</article>

```

### 4.2 `<section>` — Thematic Grouping

Defines a logical or thematic section within a document.

Common examples include chapters of a manual, separate article topics, and sections of a report.

```

<section>
    <h2>Introduction</h2>
    <p>This section introduces HTML5.</p>
</section>

<section>
    <h2>HTML5 Features</h2>
    <p>This section explains HTML5 features.</p>
</section>

```

Difference between `<article>` and `<section>`:

- `<article>` represents independent, self-contained content.
- `<section>` represents a thematic subdivision of content.
- An `<article>` may contain multiple `<section>` elements.

### 4.3 `<header>` — Introductory Content

Defines introductory content for a webpage, article, or section.

It may contain a title, subtitle, logo, author information, or other introductory elements.

```

<header>
    <h1>My Website</h1>
    <p>Learning HTML5</p>
</header>

```

A document can contain multiple `<header>` elements because individual articles and sections may have their own headers.

### 4.4 `<footer>` — Footer Information

Defines footer information associated with a webpage or section.

Common content includes copyright notices, author details, contact information, and related links.

```

<footer>
    <p>Copyright 2026 My Website</p>
    <p>Contact: info@example.com</p>
</footer>

```

A `<footer>` does not necessarily have to appear at the bottom of the entire webpage. An individual `<article>` can also contain its own footer.

## 5. HTML5 Grouping Elements

### 5.1 `<aside>` — Supplementary Content

The `<aside>` element contains content that is indirectly related or supplementary to the main discussion.

Common examples include sidebars, related articles, supplementary explanations, and resource links.

```

<article>
    <h2>Introduction to HTML5</h2>
    <p>HTML5 introduces semantic elements.</p>
</article>

<aside>
    <h3>Related Resources</h3>
    <p>Learn more about CSS and JavaScript.</p>
</aside>

```

The purpose of `<aside>` is to provide additional information without interrupting the primary content.

### 5.2 `<figure>` — Self-Contained Content

The `<figure>` element groups self-contained content referenced by the main document.

It can contain images, charts, illustrations, diagrams, and code examples.

### 5.3 `<figcaption>` — Figure Caption

The `<figcaption>` element provides a caption or description for the content inside `<figure>`.

```

<figure>
    <img src="chart.png" alt="Sales chart">

    <figcaption>
        Figure 1: Annual sales performance.
    </figcaption>
</figure>

```

Important relationship: `<figcaption>` belongs inside `<figure>` and describes its contents.

## 6. Navigation Elements: `<nav>`

The `<nav>` element defines a section containing major navigational links.

Its purpose is to help users navigate between webpages or between different sections of the same webpage.

```

<nav>
    <a href="index.html">Home</a>
    <a href="about.html">About</a>
    <a href="services.html">Services</a>
    <a href="contact.html">Contact</a>
</nav>

```

### Navigation vs. Grouping Elements

| Feature          | Navigation (`<nav>`)            | Grouping elements                           |
| ---------------- | ------------------------------- | ------------------------------------------- |
| Primary function | Organize major navigation links | Organize related content                    |
| Semantic meaning | Identifies a navigation region  | Varies by element                           |
| Examples         | Menus, table-of-contents links  | Articles, figures, supplementary content    |
| Typical tags     | `<nav>`                         | `<div>`, `<section>`, `<aside>`, `<figure>` |

Key distinction: `<nav>` specifically identifies navigation content, whereas grouping elements organize content according to their respective purposes. Not every collection of hyperlinks needs a `<nav>` element.

## 7. HTML Comments

HTML comments allow developers to document or explain code without displaying the comments on the rendered webpage.

### Syntax

```

<!-- This is an HTML comment -->

<!-- Navigation section -->
<nav>
    <a href="index.html">Home</a>
</nav>

```

### Characteristics

- Comments are ignored during normal webpage rendering.
- They help developers explain the purpose of code.
- They can improve maintainability.
- They are visible when someone inspects the page's source code.

Important: HTML comments are not private or secure. Sensitive information should never be stored in comments.

## 8. Complete Example: HTML5 Semantic Page

The following example combines the major elements discussed in this lesson.

```

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>HTML5 Example</title>
</head>

<body>

    <header>
        <h1>Technology News</h1>
        <p>Latest updates in technology</p>
    </header>

    <nav>
        <a href="index.html">Home</a>
        <a href="news.html">News</a>
        <a href="about.html">About</a>
    </nav>

    <main>
        <article>

            <header>
                <h2>Introduction to HTML5</h2>
                <p>Published in 2026</p>
            </header>

            <section>
                <h3>What is HTML5?</h3>
                <p>
                    HTML5 introduces semantic
                    elements for web development.
                </p>
            </section>

            <section>
                <h3>HTML5 Features</h3>

                <figure>
                    <img src="html5.png"
                         alt="HTML5 logo">

                    <figcaption>
                        Figure 1: HTML5 Logo
                    </figcaption>
                </figure>
            </section>

            <footer>
                <p>Article by Web Developer</p>
            </footer>

        </article>

        <aside>
            <h3>Related Topics</h3>
            <p>Learn about CSS and JavaScript.</p>
        </aside>
    </main>

    <footer>
        <p>Copyright 2026 Technology News</p>
    </footer>

</body>
</html>

```

This example also introduces `<main>`, an HTML5 element that identifies the dominant content of the document. It distinguishes primary page content from repeated site elements such as navigation and site footers.

## 10. Key Takeaways

1. HTML5 semantic elements give structure and meaning to web content.
2. `<div>` is a generic container that groups content without describing its meaning.
3. `<article>` and `<section>` serve different purposes: an article is independent content, while a section is a thematic grouping.
4. `<header>` and `<footer>` define introductory and footer content for a webpage or individual section.
5. `<aside>` provides supplementary information related to the main discussion.
6. `<figure>` and `<figcaption>` work together to present self-contained content and its caption.
7. `<nav>` identifies major navigational links.
8. HTML comments document the source code without appearing on the rendered page.

The most important principle is to use semantic HTML elements to define what content means, and CSS to control how that content looks.
