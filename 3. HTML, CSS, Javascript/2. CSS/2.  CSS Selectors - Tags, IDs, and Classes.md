CSS Selectors Overview

## What Are CSS Selectors?

CSS selectors are patterns used to select and style HTML elements. They define the relationship between HTML elements and the styles applied to them.

## Why Are Selectors Important?

- They allow precise targeting of specific HTML elements.
- They help create consistent and visually appealing designs.
- They provide flexibility and control over a website's visual presentation.

## Tag Selectors

Tag selectors target HTML elements by their tag names. A tag selector applies its styles to every instance of that tag.

### Syntax

```css
tagName {
  /* Styles for elements with the specified tag name */
}
```

Replace `tagName` with the HTML tag you want to style.

### Example: Styling Headings

```css
h1 {
  color: #3366cc;
  font-size: 24px;
}
```

This rule targets every `<h1>` element and applies:

- A blue text color
- A font size of `24px`

## ID Selectors

ID selectors target one HTML element through its unique `id` attribute. They use a hash symbol (`#`) followed by the ID value.

An ID should uniquely identify an element within an HTML document.

### Syntax

```css
#yourID {
  /* Styles for the element with the specified ID */
}
```

Replace `yourID` with the ID assigned to the HTML element.

### Example: Styling a Unique Element

```css
#header {
  background-color: #f0f0f0;
  padding: 10px;
}
```

This rule targets the element whose attribute is `id="header"` and applies:

- A light gray background
- `10px` of padding

## Class Selectors

Class selectors target HTML elements through their `class` attributes. Unlike an ID, the same class can be assigned to multiple elements. Class selectors use a period (`.`) followed by the class name.

### Syntax

```css
.className {
  /* Styles for elements with the specified class */
}
```

Replace `className` with the class you want to style.

### Example: Styling Multiple Elements

```css
.highlight {
  background-color: #ffd700;
  color: #333;
}
```

This rule targets every element whose class includes `highlight` and applies:

- A yellow background
- A dark text color

## Selector Comparison

| Selector type | Syntax example | Targets |
| --- | --- | --- |
| Tag | `h1` | Every element with that tag name |
| ID | `#header` | The element with that unique ID |
| Class | `.highlight` | Every element with that class |

## Summary

CSS selectors control which HTML elements receive particular styles:

- **Tag selectors** style groups of elements with the same tag.
- **ID selectors** style a uniquely identified element.
- **Class selectors** apply reusable styles to multiple elements.

Together, these selectors provide a flexible foundation for controlling a website's appearance.

## Key Takeaway

Use a tag selector for broad element styling, an ID selector for one unique element, and a class selector for reusable styles shared by multiple elements.
